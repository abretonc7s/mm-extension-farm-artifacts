## Known gaps in the evidence

- The full-width capture still carries the Forex filter from the preceding step, so it proves the
  pill set and the absent `More` trigger rather than the default unfiltered state.
- The sort direction renders `ArrowDown` (a chevron) rather than the design's `Arrow2Down` arrow.
  `Arrow2Down` resolves to `undefined` on the design-system install CI uses and `Icon` then renders
  nothing, so the reliably-present name was chosen; flagged in the PR description for the designer.
- The design's filter buttons sit flush while the implementation keeps an 8px gap, which changes how
  many fit before the trigger appears. Raised for the designer rather than guessed at.
