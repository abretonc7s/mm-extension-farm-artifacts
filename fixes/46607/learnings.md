- Removing a shared constant races with main: #45986 landed a new `PERPS_EVENT_PROPERTY.BUTTON_TYPE` call site after this PR dropped the alias, so CI (merge ref) failed with TS2339 while the branch was green. When a PR deletes a key, rebase and `git grep` for it right before pushing, and run a full `tsc` rather than trusting the branch-only jest run.
- `objectContaining` can't catch a leftover legacy key. Pair it with `not.toHaveProperty('button_type')` whenever the fix is a rename.
- Recipe navigation drifted: main added a flag-gated bottom nav (`bottom-nav-perps`) that hides `account-overview__perps-tab` on some launches. A selector union covers both layouts without changing the assertions.
- The analytics collector port is CDP+1000 (8666 here), not a fixed 8667. The build's `SEGMENT_HOST` has to match it, or you pin the collector with `SEGMENT_MOCK_PORT`. Also, a fresh launch drops the MetaMetrics opt-in: the fixture doesn't carry it, and `set_consent` sets it but still throws.
