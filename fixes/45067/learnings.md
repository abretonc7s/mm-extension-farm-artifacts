- Retry-then-throw masking: bugbot flagged that a `try/catch` wrapping both the recovery `init()` call and the retried operation swallows a real error from the retry itself, returning the original (misleading) failure instead. Fix-bug should scope `try/catch` around recovery-only steps and let the retried operation's own throw propagate — a comment saying "recovers from X" is not license to also mask failures unrelated to X.
- Value-equality staleness guard: bugbot caught that gating a "prefer this cached read over the stream" decision on raw value equality (`cached === current`) breaks when the stream later revisits the same numeric value — the guard can't distinguish "still stale" from "moved away and came back to the same number." Fix-bug should reach for a monotonic revision/generation counter instead of value comparison whenever adopting a point-in-time read that must be invalidated by any subsequent stream update, not just a differing one.
- Rebasing a long-lived PR branch across an upstream package migration (here: an analytics-contract move from local constants to `@metamask/perps-controller`) can silently drop content that looks redundant with the new upstream spread but isn't — test mocks lag behind real packages. When resolving a rebase conflict by preferring "the upstream already provides this," verify the specific consumer (including test mocks) actually has it before deleting the local definition.
