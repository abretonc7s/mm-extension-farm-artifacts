## Evidence integrity

- **Capture provider.** All 9 images are in-run `capture-helper snapshot` captures — `artifact-manifest.json` records `provider: capture-helper` for every one, with zero `Page.captureScreenshot` fallbacks. Earlier runs of this recipe did fall back on 3 of 9; the cause was found and fixed rather than worked around (below).
- **Root cause of the earlier fallbacks** (worth keeping for the next run): orphaned `capture-helper` processes hold the macOS capture session and wedge subsequent snapshots — a healthy snapshot takes ~0.1s, a contended one hangs to the timeout. `pkill` (SIGTERM) does **not** clear them; `pkill -9` does. The recipe now clears the capture slot with SIGKILL before every `ui.screenshot`, which took the run from 6/9 to 9/9 native captures. Note the runner reports `pass` even when it silently falls back, so the provider must be audited in `artifact-manifest.json` — a green run is not evidence of valid images.
- **HUD.** The HUD strip matches the active node intent where visible — e.g. the AC5 image reads `RUN 82/102 | AC5: capture the compact (popup-width) half of the responsive claim`.
- **State carry-over in later images.** The recipe runs one continuous session, so `evidence-ac5-*` and `evidence-pr5-*` inherit the `Size (ETH)`/`Size (BTC)` denomination applied in PR3 and (for AC5) the Limit prefill from PR4. This is stated rather than implied — those images do not depict default settings.
- **Pruning.** No orphan `baseline.png` / `final.png` was produced. AC4 and PR1 are grouped onto the AC2 capture instead of emitting near-identical duplicates.

Reverting the PR removes `perps-order-book-toggle` from the market header, so `ac1-wait-toggle-affordance` fails and every downstream node fails with it. Beyond mere presence, the assertions are behavioural: the USD-value probe, the `aria-valuenow` step/clamp assertions, the drag bounds check, the tapped-price↔limit-input comparison and the cross-market disjointness check would each fail independently if the corresponding behaviour regressed.
